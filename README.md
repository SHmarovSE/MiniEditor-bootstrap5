# MiniEditor-bootstrap5
Ультра-легковесный, расширяемый WYSIWYG/HTML текстовый редактор на чистом JavaScript (ES6). Он разработан специально для интеграции с **Bootstrap 5** и **Bootstrap Icons**, не имеет сторонних JS-зависимостей (0 Кб внешнего кода) и не использует тяжелые иконочные шрифты вроде Font Awesome.
