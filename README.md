# 📝 MiniEditor (Bootstrap 5)

**MiniEditor** — это ультра-легковесный, расширяемый WYSIWYG/HTML текстовый редактор на чистом JavaScript (ES6). Он разработан специально для интеграции с **Bootstrap 5** и **Bootstrap Icons**, не имеет сторонних JS-зависимостей (0 Кб внешнего кода) и не использует тяжелые иконочные шрифты вроде Font Awesome.

---

## 📌 Ключевые особенности

* **Изолированный ES6-класс:** Легко импортируется и переиспользуется для нескольких текстовых полей на одной странице.
* **Нативная синхронизация:** Автоматически и «на лету» обновляет исходный тег `<textarea>`. Благодаря встроенному `MutationObserver` он нативно совместим с любыми внешними скриптами автозаполнения форм (например, функциями типа `fillForm`).
* **Умный блок кода:** Генерация валидных изолированных тегов `<pre><code>` с предсказуемым выходом наружу по двойному нажатию клавиши `Enter`.
* **Защита от мусора (Plain Text Paste):** Автоматическая очистка текста от чужих инлайн-стилей и лишней разметки при копировании из Word, сайтов или сред разработки (IDE).
* **Интеграция с модалками Bootstrap:** Автоматический сброс полноэкранного режима (`modal-fullscreen`) при закрытии модального окна.
* **Вишенка на торте (Расширяемость):** Динамическая генерация выпадающего меню «Дополнительно» для привязки внешних функций вашего приложения (справочники, API, плагины).

## 🛠 Установка и подготовка

### 1. Системные требования (Глобальные стили)
Убедитесь, что на странице подключены Bootstrap 5 и Bootstrap Icons. 

Добавьте следующие стили в ваш глобальный CSS-файл проекта (например, `app.css` или `style.css`), чтобы блоки кода отображались корректно как внутри редактора, так и на лицевой части сайта при выводе из базы данных:

```css
/* Глобальные стили для отображения блоков кода */
.custom-code-block, 
pre.custom-code-block code {
    background-color: #f8f9fa !important;
    color: #212529 !important;
    font-family: var(--bs-font-monospace) !important;
    font-size: 0.875rem !important;
}
pre.custom-code-block {
    display: block !important;
    border: 1px solid #dee2e6 !important;
    border-radius: 0.375rem !important;
    padding: 0.75rem 1rem !important;
    margin: 1rem 0 !important;
    white-space: pre-wrap !important; /* Автоперенос длинных строк */
    word-break: break-all !important;
}
```

### 2. Подключение через CDN (jsDelivr)

Вы можете подключить последнюю стабильную версию редактора напрямую к вашему сайту:

```html
<!-- Подключение JavaScript-модуля MiniEditor -->
<script src="https://cdn.jsdelivr.net/gh/SHmarovSE/MiniEditor-bootstrap5@latest/MiniEditor.js" type="module"></script>
```

## 🚀 Использование и API

### Параметры инициализации (`options`)
При создании экземпляра класса `new MiniEditor(selector, options)` можно передать объект настроек:

| Параметр | Тип | По умолчанию | Описание |
| :--- | :--- | :--- | :--- |
| `height` | String | `'250px'` | Начальная минимальная высота поля ввода. |
| `maxHeight` | String | `'400px'` | Максимальная высота поля, после которой включается вертикальный скролл. |
| `placeholder` | String | `'Введите текст...'` | Текст-заглушка, если исходный textarea пуст. |
| `buttons` | Array | `[]` | Массив объектов для генерации кнопок в меню «Дополнительно». |

#### Структура объекта в массиве `buttons`:
* **`label`** *(String)*: HTML-код содержимого пункта (например, иконка + название).
* **`title`** *(String)*: Подсказка или серый текст-пояснение, отображаемый справа.
* **`action`** *(Function)*: Колбэк-функция, выполняемая при клике на этот пункт.

## 💡 Практические примеры

### Пример 1. Базовая инициализация (простая статья)
Обычное быстрое подключение редактора на стандартное текстовое поле.

```javascript
import MiniEditor from './MiniEditor.js';

// Инициализация с базовыми настройками размеров
const simpleEditor = new MiniEditor('#article-textarea', {
    height: '300px',
    maxHeight: '500px',
    placeholder: 'Напишите текст новости...'
});
```

### Пример 2. Продвинутая интеграция (Форма ролей + Справочники)
Пример использования кастомных кнопок в меню «Дополнительно» для глубокого взаимодействия со сторонними модулями системы.

```javascript
import MiniEditor from './MiniEditor.js';

const roleEditor = new MiniEditor('#role-description', {
    height: '200px',
    maxHeight: '400px',
    
    // Генерируем "вишенку на торте" — меню Дополнительно
    buttons: [
        {
            label: '<i class="bi bi-journal-text text-primary"></i> Открыть справочник',
            title: 'Должности', 
            action: () => {
                // Вызываем внешнюю функцию вашего приложения
                myApp.modalRegistry.open('positions', (selectedData) => {
                    // Пример вставки текста из справочника в текущую позицию курсора
                    document.execCommand('insertText', false, selectedData.name);
                });
            }
        },
        {
            label: '<i class="bi bi-shield-lock text-danger"></i> Вставить шаблон прав',
            title: 'Безопасность',
            action: () => {
                const template = `<p><b>Ограничения роли:</b></p><ul><li>Доступ к чтению</li></ul>`;
                document.execCommand('insertHTML', false, template);
            }
        }
    ]
});

// Проверка: чтение данных стандартным методом формы
document.getElementById('roleForm').addEventListener('submit', (e) => {
    e.preventDefault();
    
    // HTML-код забирается НАПРЯМУЮ из textarea без вызова методов класса!
    const resultHTML = document.getElementById('role-description').value;
    console.log('Готовый код для отправки в БД:', resultHTML);
});
```

### Пример 3. Работа в динамических интерфейсах (`fillForm`)
Если в вашем приложении данные в форму прилетают асинхронно (например, при клике на строку таблицы вызывается функция `fillForm(form, data)`), вам не нужно менять код этой функции. Благодаря встроенному `MutationObserver`, редактор сам подхватит изменения:

```javascript
// Внешняя функция заполняет стандартный textarea:
document.querySelector('#editor-id').value = selectedRow.html_content;

// Редактор MiniEditor мгновенно среагирует, обновит визуальный DIV 
// и отобразит текст, сохранив все кастомные стили и блоки кода.
```

## ⌨️ Горячие клавиши в области ввода

* **`Tab`** — сдвинуть элемент списка вправо (сделать вложенным).
* **`Shift + Tab`** — вернуть элемент списка влево (переместить на уровень выше).
* **`Enter`** *(внутри блока кода)* — делает классический перевод строки внутри серой плашки.
* **`Двойной Enter`** *(на пустой строке в конце блока кода)* — производит автоматическое «выпрыгивание» из тега `<pre>` наружу и создает обычную текстовую строку `<p>` снизу.
